키사스 앱 12월 15일 준비 계획

2026년 11월 16일 기준 · 12월 15일(화)에서 거꾸로 세운 일정 · 12월 16일(수) 선생님 사용 시작, 2027년 1월 2기 캠프에서 사용

한눈에 큰 일정 수업 운영 방식 먼저 정할 것 누구에게 무엇을 일 단위 계획 12월 15일 이후 아직 확인 못 한 것

12월 15일 전에는 수업용 기능을 새로 구축하지 않고, 크리에이터클럽의 기존 기능으로 수업을 운영합니다

12월 16일부터 선생님이 키사스 앱을 사용할 수 있도록 아래 일정으로 준비해 보려고 합니다. 세부 기획에 들어가기 전에 준비 범위와 일정에 대한 의견을 먼저 받고 싶습니다.

  1. 프로젝트 하나를 반 하나로 사용합니다. 선생님은 리더, 학생은 멤버로 참여합니다. 공지 게시판, 게시판, 일정, 자료실, 채팅방으로 과제 안내, 제출, 수업 링크, 자료 공유, 대화를 합니다.
  2. 12월 15일 전에는 별도 앱·서버 준비와 아이들의 가입·이용에 꼭 필요한 보완에 집중합니다. 준비 범위는 다섯 가지이고, 개발팀의 가능 여부와 일정을 확인한 뒤 확정합니다.
  3. 이후에는 실제 수업에서 필요한 기능을 하나씩 추가합니다. 운영표나 카카오톡으로 하던 일도 사용하면서 기능으로 옮길 필요가 있는지 판단합니다.
  4. 12월 15일은 스토어 정식 출시일이고, 앱은 키사스가 운영합니다. 약관과 스토어 등록은 이 기준으로 준비합니다. 학생 가입 방식과 12월 15일에 닫을 기능은 이번 주에 먼저 정해야 합니다.

주차별 준비 일정안: 방향 합의, 범위 확정, 필수 보완과 QA, 심사 순서입니다

스토어 심사 기간은 우리가 정할 수 없어서, 심사 제출을 12월 7일(월)로 잡고 거기서 거꾸로 세웠습니다.

항목지금 상태와 필요한 이유
1. 별도 앱, 별도 서버지금은 크리에이터클럽 AWS 계정 안에 논리적으로만 나뉘어 있습니다. 보안 담당과 별도 AWS 계정으로 나누기로 의견을 모았습니다.
2. 학생 가입·보호자 동의지금 가입은 「만 14세 이상입니다」에 체크해야 진행됩니다. 만 14세 미만이 가입하는 길과 보호자 동의를 확인하고 기록하는 길이 없습니다. 유일하게 새 화면이 필요한 곳입니다.
3. 반 밖 공개·교류 제한프로젝트, 팀 링크는 앱이 없어도 브라우저에서 열립니다. 업로드 기본값은 전체공개입니다. 노크, 1:1 채팅, 오픈채팅으로 모르는 사람과 대화가 시작됩니다.
4. 신고 글 조치신고와 차단은 있습니다. 다만 리더는 다른 멤버의 글을 지울 수 없어서, 선생님이 반 안의 부적절한 글을 바로 내리지 못합니다. 운영자가 관리 화면에서 내리는 길이 있어야 합니다.
5. 약관, 개인정보 처리방침, 보호자 동의서, 스토어 등록앱을 운영하는 키사스 명의로 준비합니다. 개인정보 책임을 어떻게 나눠 적을지는 법무 검토에서 확인합니다. 스토어 연령 등급과 개인정보 항목도 새로 적습니다.
